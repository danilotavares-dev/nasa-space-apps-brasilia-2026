# NASA Space Apps Challenge Brasília 2026

Landing page e plataforma de recrutamento para formação da equipe
organizadora do NASA Space Apps Challenge Brasília 2026.

## Objetivo

Reunir estudantes e profissionais de diferentes áreas para formar
uma equipe multidisciplinar responsável pela organização do evento.

## Stack

- React
- TypeScript
- Tailwind CSS
- Vite
